# Documentation

This directory keeps repository-side documentation that complements the GitHub wiki for `iRefinedX`.

## Structure

- `research/`: larger analysis/reference documents that are useful to keep in-repo
- `wiki/`: source pages that are published to the GitHub wiki

## Primary Documentation Entry Points

- GitHub wiki: `https://github.com/nishizumi-maho/iRefinedX/wiki`
- Releases: `https://github.com/nishizumi-maho/iRefinedX/releases`
- Third-party notices: `../THIRD_PARTY_NOTICES.md`

The repository README stays concise. Detailed feature, architecture, storage, privacy, troubleshooting and release documentation lives in the wiki.

The wiki source also carries shared assets, such as the current repository icon under `docs/wiki/assets/`.
