# League and Hosted Tools

## Goal

League and hosted pages are intended to behave like the original local iRacing UI while still exposing the useful iRefinedX desktop enhancements.

## League Pages

- Up-next and browse/session views are restored to better match the local UI structure.
- Queue and register behavior is kept separate where needed so native actions stay predictable.
- Session JSON export remains available for league workflows.

## Hosted Pages

- Hosted browsing and hosted session actions follow the same principle: native first, enhancement second.
- Create-session and session-management surfaces are aligned toward the local UI flow rather than a custom shell workflow.

## Export Tools

- Official series export buttons are shown where they fit the native layout.
- Session JSON buttons remain available for league and hosted workflows.
