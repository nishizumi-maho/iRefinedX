# Using iRefinedX

## Launch Flow

- Open iRefinedX from the Start menu, desktop shortcut, or `IRX.exe`.
- Sign in if the official iRacing web flow requires authentication.
- Navigate exactly as you would in the local UI.

## Official Racing

- The large green action button at the top follows the native local UI behavior.
- Series pages, up-next behavior, and native banners come from the official UI.
- iRefinedX enhancements are layered onto those screens instead of replacing them.

## Intelligence Center

- The dashboard Intelligence Center expands to use the available desktop width.
- It is designed to fit into the official UI layout without introducing extra side chrome.

## Bottom Queue Bar

- The bottom bar is centered and expands outward as queued sessions are added.
- Queue state survives app restarts.
- The bar updates independently of whether the user is currently inside a series page.

## Session JSON Export

- Official series export actions are available where the native layout allows them.
- League and hosted export actions remain available on their respective pages.
